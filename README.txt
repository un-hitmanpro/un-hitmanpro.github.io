HitmanPro Support Guides Website

This independent static website contains 50 HitmanPro educational help articles.

Files:
- index.html: Homepage
- blog.html: Article directory
- support.html: Support information
- articles/: 50 individual article pages
- sitemap.xml: XML sitemap covering all HTML pages
- robots.txt: Allows crawling and points to the sitemap

IMPORTANT: Before publishing, replace https://YOUR-DOMAIN/ in sitemap.xml and
https://YOUR-DOMAIN/sitemap.xml in robots.txt with your actual website's
canonical HTTPS domain, including any GitHub Pages repository path if applicable.

Upload the extracted files and folders to the root of your hosting repository.
